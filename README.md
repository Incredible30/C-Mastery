# C Mastery Platform

A C programming learning platform built with Next.js 15, TypeScript, Tailwind CSS and Supabase.

- **Setup and usage:** [docs/INSTRUCTION_BOOK.md](docs/INSTRUCTION_BOOK.md)
- **Progress and roadmap:** [docs/DEVELOPMENT_CHECKLIST.md](docs/DEVELOPMENT_CHECKLIST.md)

```bash
npm install
cp .env.example .env.local   # then fill in your Supabase keys
npm run dev
```

Run `npm run check` before every commit.
