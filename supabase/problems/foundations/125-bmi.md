Body Mass Index is weight in kilograms divided by the square of height in **metres**. Height is given in centimetres, so convert it first.

**Input:** two numbers: weight in kg and height in cm.

**Output:** the BMI with 1 decimal place.

**Constraints:** 1 ≤ weight ≤ 500, 50 ≤ height ≤ 250

## Hints

1. Divide the height by 100.0 to get metres.
2. BMI = weight / (m × m). Print with `%.1f`.

```c starter
#include <stdio.h>

int main(void) {
    double kg, cm;
    scanf("%lf %lf", &kg, &cm);
    /* print the BMI */
    return 0;
}
```

```c solution
#include <stdio.h>

int main(void) {
    double kg, cm;
    if (scanf("%lf %lf", &kg, &cm) != 2) return 1;
    double m = cm / 100.0;
    printf("%.1f\n", kg / (m * m));
    return 0;
}
```
